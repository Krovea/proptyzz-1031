# 1031.proptyzz.com

The landing page linked from the 1031 outreach emails. One static page
(`index.html`), published by GitHub Pages from `main`; `CNAME` holds the
custom domain. DNS: a CNAME record `1031` → `krovea.github.io` at GoDaddy.

Rules for the content (Reg D 506(b) and CAN-SPAM context): education only,
no named properties, sponsors, returns or offerings, no urgency beyond the
statutory 45/180-day deadlines, no tax advice.

To change it: edit `index.html`, open a pull request, merge. Pages
republishes within a minute or two.
